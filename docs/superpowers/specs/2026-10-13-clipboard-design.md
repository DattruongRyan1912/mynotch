# MyNotch — Clipboard (dự án con 1)

- **Ngày:** 2026-10-13
- **Trạng thái:** Triển khai trên nhánh `feat/modules`, sau dự án con 0.5 (điểm nối nền tảng)
- **Tham chiếu hành vi:** OneNotch 2.0.5, điều tra clean-room bằng REA + đọc metadata/chuỗi giao diện. Không chép mã; chỉ tham khảo hành vi.

## 1. Mục tiêu

Lịch sử clipboard ngay trong notch: tự ghi lại mọi thứ người dùng copy, tìm nhanh, copy/dán lại bằng một click hoặc bàn phím, ghim vào board.

**Trong phạm vi:**

- Ghi lại: văn bản, rich text (RTF), link, mã màu, ảnh, file.
- Bỏ qua dữ liệu nhạy cảm (đánh dấu `Concealed`/`Transient`/`AutoGenerated`), app bị loại trừ và trạng thái tạm dừng.
- Lưu trên đĩa, giới hạn số mục, thời gian giữ và dung lượng ảnh.
- Tab "Clipboard" trong notch: tìm kiếm, lọc theo loại, board, thẻ dạng băng chuyền ngang, điều khiển bằng bàn phím, menu ngữ cảnh, kéo thẻ ra app khác.
- Board: tạo, đổi tên, xoá, ghim và bỏ ghim mục. Mục đã ghim không bị dọn tự động.
- Biến đổi văn bản: hoa/thường, viết hoa chữ đầu, bỏ khoảng trắng thừa, bỏ dòng trống, sắp xếp dòng, JSON format/minify, Base64 và URL encode/decode.
- Phím tắt ⌃⌥V mở notch ở tab Clipboard.
- Dán trực tiếp vào app đang dùng (cần quyền Accessibility, tuỳ chọn).

**Ngoài phạm vi:**

- Đồng bộ iCloud: CloudKit cần tài khoản trả phí.
- Board khoá bằng mật mã.
- Xem trước link: cần mạng, trái nguyên tắc không gửi dữ liệu ra ngoài.
- Cửa sổ Library riêng và panel nổi cạnh con trỏ.
- Copy Stack / hàng đợi dán.
- Máy chủ MCP cho AI agent: xét lại ở dự án con AI.
- Import từ app khác.

## 2. Hành vi tham chiếu (OneNotch, rút gọn)

| Mặt | OneNotch | MyNotch |
|---|---|---|
| Phát hiện thay đổi | Poll `changeCount` mỗi 0,15 s trên queue nền | Poll mỗi 0,3 s qua `context.scheduler` trên main actor; chỉ đọc nội dung khi `changeCount` đổi |
| Loại nội dung | text, link, richText, color, image, file, files | Giống |
| Nhạy cảm | Bỏ qua `org.nspasteboard.ConcealedType/TransientType/AutoGeneratedType` (mặc định bật) | Giống |
| Loại trừ app | Danh sách bundle ID; bỏ qua khi app đó đang ở trước | Giống |
| Trùng lặp | Copy lại một mục có sẵn không tạo mục mới | Băm nội dung; trùng thì đưa mục cũ lên đầu |
| Lưu trữ | SQLite (GRDB), ảnh PNG riêng | JSON + ảnh PNG riêng (đủ cho 5000 mục, không thêm thư viện) |
| Giới hạn | 500 mục, giữ ~1 tháng, ảnh 250 MB | Giống, chỉnh được |
| Click | copy / copy & đóng / dán / dán & đóng | `copy` hoặc `paste`, kèm tuỳ chọn đóng notch |
| Dán trực tiếp | Ghi pasteboard, gửi ⌘V bằng CGEvent, cần Accessibility | Giống |
| Phím tắt mặc định | ⇧⌘C (panel) | ⌃⌥V (đồng bộ với ⌃⌥N) |

### 3.1 Phân loại (theo thứ tự ưu tiên)

1. Có type nhạy cảm và cài đặt `ignoreSensitive` bật → bỏ qua (`sensitive`).
2. Có type `io.lucasvu.mynotch.clipboard` (MyNotch tự ghi) → bỏ qua (`ownWrite`).
3. Có file URL (`public.file-url`) → `files([URL])`.
4. Có ảnh PNG hoặc TIFF → `image` (TIFF đổi sang PNG trước khi lưu).
5. Có chuỗi:
   - chỉ là một URL `http/https/mailto` (sau khi bỏ khoảng trắng hai đầu) → `link`;
   - là mã màu hex `#RGB`, `#RRGGBB`, `#RRGGBBAA` (không cần `#` nếu `colorsWithoutHash` bật và chuỗi đúng 6 hoặc 8 ký tự hex) → `color`;
   - có RTF đi kèm → `richText(plain, rtf)`;
   - còn lại → `text`.
6. Chuỗi rỗng hoặc chỉ khoảng trắng → bỏ qua (`empty`). Văn bản dài hơn 2 MB → bỏ qua (`tooLarge`).

### 3.2 Lịch sử và giới hạn

- Mỗi mục có `contentHash` (SHA-256 của dạng chuẩn hoá: text = chuỗi, ảnh = dữ liệu PNG, file = danh sách đường dẫn).
- Copy trùng hash → cập nhật thời điểm và app nguồn, đưa lên đầu; không tạo mục mới.
- Dọn sau mỗi lần thêm và khi khởi động:
  - quá `historyLimit` mục,
  - cũ hơn `retention`,
  - tổng dung lượng ảnh vượt `imageStorageLimitMB` (xoá ảnh cũ nhất trước).
- Mục nằm trong bất kỳ board nào không bị dọn. File ảnh của mục bị xoá cũng bị xoá khỏi đĩa.
- Xoá lịch sử theo khoảng: 15 phút, 1 giờ, 1 ngày, 1 tuần, tất cả. Không đụng mục đã ghim.

### 3.3 Lưu trữ

- Thư mục `context.storage.directory`:
  - `history.json`: danh sách mục, mới nhất trước;
  - `boards.json`: board và id các mục đã ghim;
  - `images/<hash>.png`: ảnh.
- Ghi theo kiểu atomic, trễ 1 giây sau thay đổi cuối (gom nhiều thay đổi), ghi ngay khi module dừng.
- File hỏng: đổi tên thành `history.corrupt-<thời điểm>.json` rồi bắt đầu lịch sử trống, ghi log lỗi. Không crash.

### 3.4 Thao tác

| Thao tác | Kết quả |
|---|---|
| Click thẻ / Return | `clickAction`: `copy` đưa lên pasteboard; `paste` đưa lên pasteboard rồi dán. Sau đó đóng notch nếu `closeAfterAction` bật |
| Menu ngữ cảnh | Copy, Dán, Copy dạng văn bản thuần, Biến đổi ▸, Ghim vào board ▸ / Bỏ ghim, Mở link, Hiện trong Finder, Xoá |
| Kéo thẻ ra ngoài | `NSItemProvider` theo loại nội dung; notch giữ mở khi đang kéo (`setDragging`) |

- **Dán trực tiếp:** ghi pasteboard, đóng notch, đợi 80 ms để bàn phím về app trước, rồi gửi ⌘V (CGEvent, key code 9, cờ Command).
- **Chưa có quyền Accessibility:** chỉ copy và hiện activity "Đã chép — nhấn ⌘V để dán".
- **Đánh dấu:** mọi lần MyNotch ghi pasteboard đều kèm type đánh dấu `io.lucasvu.mynotch.clipboard`, nên monitor không ghi lại chính nó. Mục được dùng lại được đưa lên đầu lịch sử.

### 3.5 Giao diện

- Tab "Clipboard" (`acceptsKeyboard: true`, cao 230 pt):
  - hàng trên: ô tìm kiếm, nút lọc loại (Tất cả, Văn bản, Link, Ảnh, File, Màu) và các board (Tất cả + từng board + nút thêm);
  - bên dưới: băng chuyền ngang các thẻ 112×120 pt.
- Thẻ: xem trước theo loại (văn bản 4 dòng, ảnh thu nhỏ, ô màu, link kèm host, icon file + tên), icon app nguồn, thời gian tương đối, dấu ghim.
- Bàn phím:
  - ô tìm kiếm luôn có focus khi mở tab;
  - ↓/→ chọn thẻ kế, ↑/← chọn thẻ trước; ←/→ chỉ đổi thẻ khi ô tìm kiếm trống;
  - Return thực hiện `clickAction`;
  - Esc xoá chuỗi tìm kiếm nếu có, còn không thì đóng notch.
- Menu ngữ cảnh và hộp nhập tên board ghim notch (`setPinned`) trong lúc mở.
- **Activity "Đã chép":** khi ghi lại được một mục mới và `showCopiedActivity` bật, hiện icon clipboard + loại nội dung trong 1,5 s.

### 3.6 Cài đặt (`module.clipboard.*`)

| Khoá | Mặc định | Ghi chú |
|---|---|---|
| `paused` | false | Tạm dừng ghi |
| `historyLimit` | 500 | 50…5000 |
| `retention` | `month` | `day`, `week`, `month`, `year`, `forever` |
| `imageStorageLimitMB` | 250 | 50…2000 |
| `ignoreSensitive` | true | |
| `excludedBundleIDs` | [] | Chọn app qua bảng chọn file `.app` |
| `clickAction` | `copy` | `copy`, `paste` |
| `closeAfterAction` | true | |
| `showCopiedActivity` | true | |
| `colorsWithoutHash` | true | |

Trang Settings có thêm: nút "Xoá lịch sử…" theo khoảng, dung lượng đang dùng, trạng thái quyền.

### 3.7 Quyền

- **Accessibility:** quyền tuỳ chọn (`optionalPermissions`), chỉ để dán trực tiếp.
- **Pasteboard:** thêm `Permission.pasteboard`.
  - Trạng thái lấy từ `NSPasteboard.general.accessBehavior`: `alwaysAllow` → granted, `alwaysDeny` → denied, còn lại → notDetermined.
  - macOS 26 có thể hỏi mỗi lần app đọc pasteboard. Settings hướng dẫn chọn "Luôn cho phép" trong System Settings → Quyền riêng tư & Bảo mật → Dán từ app khác.
  - Khi `alwaysDeny`, module vẫn chạy nhưng tab hiện hướng dẫn thay vì lịch sử trống.

## 4. Xử lý lỗi

- Đọc pasteboard trả về nil hoặc type lạ → bỏ qua, không log ồn ào.
- Ghi file thất bại → log lỗi, giữ dữ liệu trong bộ nhớ, thử lại ở lần lưu sau.
- Ảnh không giải mã được → bỏ qua mục đó.

| Store | Ghi rồi đọc lại; ghi trễ gom thay đổi (ManualScheduler); flush khi dừng; file hỏng được đổi tên |
