Trước khi kiểm

  • Thoát OneNotch và các app notch khác (hai app cùng chiếm vùng notch).
  • Chỉ chạy một bản MyNotch. Bản Debug (DerivedData) và bản Release (/Applications) nằm ở hai đường dẫn khác nhau; mở cả hai sẽ thành hai notch chồng nhau. Thoát bản cũ (menu bar → Quit MyNotch) trước khi mở bản kia.
  • Mục có nhãn Quyền: … chạm quyền hệ thống, API riêng: … chạm API riêng của macOS, … sửa file ngoài app, gửi dữ liệu ra mạng, cần điều kiện riêng (tài khoản Apple Music, Chrome ở Developer mode, bản Debug, hai màn hình, Claude Code đang chạy, MacBook chạy pin) hoặc cần xem kết quả cụ thể.   • Không thử bằng dữ liệu thật nhạy cảm (mật khẩu, prompt riêng tư). Agent và test tự động không bao giờ đọc ~/.claude hay ~/.codex; mục AI agents dưới đây là lần đầu hook chạm vào file thật của bạn.
